# 第19届智能车竞赛 · 智能视觉代码与资源分享

本仓库整理参加第19届智能车比赛时保留的智能视觉工程，同时分享收集到的智能车开源资源。工程用于学习比赛代码中的视觉处理、底盘控制和外设协作；历史比赛参数需结合实际硬件重新核对。

## 内容入口

- [智能车开源资源导航](docs/开源资料导航.md)：按组别整理收集到的外部项目。


## 工程结构

```text
Project/
  user/src/       main.c 入口、isr.c 中断服务
  user/inc/       中断头文件
  code/           图像处理、圆环/十字/障碍/斑马线等模块
  bsp/            初始化、运动控制、PID、路径流程、通信与显示
  iar/            IAR 工作区、工程与链接配置
  mdk/            Keil 工程、下载初始化与链接配置
  *.txt, *.xlsx   原有推荐引脚与核心板引脚资料
libraries/
  zf_common/      逐飞公共支持
  zf_driver/      底层驱动
  zf_device/      外设驱动及预编译配置库
  sdk/           NXP SDK、CMSIS、启动与板级代码
  components/    FatFs、USB、SD/MMC 等组件
  doc/           原有配置说明、版本记录和许可声明
docs/            本次新增说明与资源导航
```

## C 文件说明

### `Project/bsp`：初始化、底盘控制与比赛流程

| 文件 | 用途 |
| --- | --- |
| `ant.c` | 蚁群算法，根据输入点位搜索访问顺序。 |
| `bluetooth.c` | 保留的蓝牙串口收发与数据解析代码，目前实现已注释。 |
| `carry.c` | 搬运机构控制，包括舵机动作、拾取、翻转、收纳和图片放置。 |
| `define.c` | 集中定义全局变量、控制参数、通信缓存和比赛状态。 |
| `display.c` | 五向按键初始化、扫描，以及准备和调试操作。 |
| `filter.c` | 数据队列维护与滤波处理。 |
| `flash_param.c` | 空文件，暂无实现。 |
| `fmath.c` | 通用数学辅助函数，包括平方根、倒平方根、绝对值、符号和归一化。 |
| `gyroscope.c` | IMU 数据读取、零偏校准、姿态融合与欧拉角计算。 |
| `Init.c` | 系统与外设初始化，包括定时器、电机 PWM、PID、编码器、视觉和通信。 |
| `massage.c` | 按模式输出姿态、速度、PID 和比赛状态等调试数据。 |
| `MatKey.c` | 矩阵键盘初始化、扫描和按键读取。 |
| `moter.c` | 底盘运动学计算、编码器处理、轮速分配和电机控制。 |
| `openart_uart.c` | OpenART 串口初始化、接收中断、数据接收与发送。 |
| `pid.c` | 位置、速度、角度及角速度等控制计算，以及移动控制接口。 |
| `route_planning.c` | 比赛主流程，组织巡线、姿态校正、元素处理、图片拾放和 OpenART 消息交互。 |
| `system.c` | 保留的系统模块框架，目前只有文件说明和头文件引用。 |
| `tofa.c` | ToF 测距数据采集、刷新统计与距离条件判断。 |

### `Project/code`：图像处理与赛道元素

| 文件 | 用途 |
| --- | --- |
| `barrier_left.c` | 左侧障碍识别与相关拐点计算。 |
| `barrier_right.c` | 右侧障碍识别、相关拐点及单调性判断。 |
| `circle_left.c` | 左圆环识别与处理，包括入环、拐点和边线特征判断。 |
| `circle_right.c` | 右圆环识别与处理，包括入环、拐点和边线特征判断。 |
| `control.c` | 空文件，暂无实现。 |
| `cross.c` | 十字识别与处理，包含边线拟合、拐点搜索和补线辅助函数。 |
| `image.c` | 摄像头与显示初始化、图像裁剪、Otsu 阈值、左右手巡线、边线处理、中线计算与图像显示。 |
| `My_math.c` | 视觉处理辅助计算，包括斜率、三角形面积、长直道与黑白区域判断。 |
| `situation.c` | 根据中线数据计算巡线偏差。 |
| `zebra.c` | 斑马线识别。 |
